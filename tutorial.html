HydroTGNN 튜토리얼: USGS 유량 데이터 → tsl 시공간 그래프 신경망¶

이 노트북은 이 저장소의 분석 코드가 어떤 순서로, 어떤 객체를 거쳐 동작하는지 단계별로 보여줍니다.

CSV (adj_matrix, discharge)
  → IJCNNHydrologyDataset   (pandas 기반, tsl TabularDataset)      ... 2~4절
  → get_connectivity()       (인접행렬 → edge_index / edge_weight)   ... 4절
  → add_missing_values()     (결측 마스크: mask / eval_mask)          ... 5절
  → ImputationDataset        (torch 기반, 슬라이딩 윈도우 샘플)       ... 6절
  → SpatioTemporalDataModule (스케일링 + train/val/test 분할)        ... 7절
  → Imputer + GRINModel      (LightningModule + 학습)               ... 8절
  → 평가/시각화                                                     ... 9절
  → (보너스) 예측(forecasting) 파이프라인                           ... 10절
  → Hydra 설정(spin_hydrology.yaml)과의 연결                        ... 11절

실제 USGS 데이터(IJCNN/adj_matrix.csv, IJCNN/merged_discharge_data.csv)는 저장소에 포함되어 있지 않습니다. 여기서는 같은 파일 형식의 합성 하천망 데이터를 만들어 사용합니다. 실제 데이터가 있으면 2절의 경로만 바꾸면 됩니다.

2. 합성 하천망 데이터 만들기¶

IJCNNHydrologyDataset이 기대하는 두 CSV의 형식:

파일 형식
adj_matrix.csv N x N 정방행렬, 첫 열은 인덱스(관측소 ID). a[i, j] > 0 이면 i → j 로 물이 흐름(상류 → 하류).
merged_discharge_data.csv 행 = 시간, 열 = 관측소 ID, 첫 열은 datetime 인덱스. 값 = 유량(discharge). 결측은 NaN.

아래는 8개 관측소로 이루어진 작은 나무 모양의 하천망입니다. 하류 유량 = 상류 유량의 합(지연 포함) + 자체 유역 유출.

rng = np.random.default_rng(0)

# 하천망 위상: (상류 -> 하류)
gauges = [f"G{i:02d}" for i in range(8)]
edges = [(0, 2), (1, 2), (2, 4), (3, 4), (4, 6), (5, 6), (6, 7)]   # G07이 최하류 출구

N = len(gauges)
adj = np.zeros((N, N), dtype=int)
for u, v in edges:
    adj[u, v] = 1

T = 24 * 120                                   # 120일치 시간별 데이터
index = pd.date_range("2021-03-01", periods=T, freq="h")
t = np.arange(T)

# 1) 각 유역의 자체 유출: 기저유량 + 강우 이벤트에 대한 지수 감쇠 응답
def local_runoff(seed, base, n_events):
    r = np.random.default_rng(seed)
    q = np.full(T, base, dtype=float)
    for _ in range(n_events):
        start = r.integers(0, T - 72)
        peak = r.uniform(2, 8) * base
        q[start:start + 72] += peak * np.exp(-np.arange(72) / r.uniform(8, 20))
    q *= 1 + 0.15 * np.sin(2 * np.pi * t / 24)       # 일주기(눈 녹음 등) 흉내
    return q

local = {i: local_runoff(100 + i, base=rng.uniform(5, 15), n_events=12) for i in range(N)}

# 2) 라우팅: 상류에서 하류로 위상 정렬 순서대로 누적 (한 링크당 3시간 지연)
order = [0, 1, 3, 5, 2, 4, 6, 7]
Q = {i: local[i].copy() for i in range(N)}
for v in order:
    for u in range(N):
        if adj[u, v]:
            Q[v] += np.roll(Q[u], 3)
discharge = pd.DataFrame({g: Q[i] for i, g in enumerate(gauges)}, index=index)
discharge += rng.normal(0, 0.3, discharge.shape)          # 센서 잡음

# 3) 실제 USGS 데이터처럼 원본에도 결측(센서 다운타임)을 조금 넣어 둔다
for g in rng.choice(gauges, 3, replace=False):
    s = rng.integers(0, T - 48)
    discharge.loc[discharge.index[s:s + 48], g] = np.nan

3-1. 네 가지 주의점 (그대로 학습에 쓰기 전에 알아야 할 것)¶

(a) 마스크의 의미가 tsl 규약과 반대입니다. tsl에서 mask는 관측된(valid) 값이 True 입니다. 그런데 create_mask()는 df.isna() (결측이 True)를 반환하고 self.mask에 DataFrame을 그대로 넣습니다. tsl의 TabularDataset(mask=...) 인자로 넘기면 내부적으로 파싱·정규화되므로, 아래에서는 mask = ~df.isna()를 생성자에 넘기도록 고칩니다.

(b) get_connectivity(method='distance')가 동작하려면 compute_similarity를 구현해야 합니다. TabularDataset의 compute_similarity는 NotImplementedError를 던지고, get_similarity는 similarity_options를 검사합니다. tsl의 MetrLA 데이터셋과 같은 방식으로 거리행렬에 가우시안 커널을 씌워 유사도(=엣지 가중치)로 만듭니다.

(c) 시간 공변량(datetime_encoded)은 DatetimeDataset에만 있습니다. 예제 스크립트는 dataset.datetime_encoded('day')로 시각 인코딩을 만드는데, 이 메서드는 TabularDataset이 아니라 DatetimeDataset(= TabularDataset + TemporalFeaturesMixin)에 있습니다. tsl의 내장 데이터셋(MetrLA 등)도 모두 DatetimeDataset을 상속합니다.

(d) 엣지 방향이 뒤집힙니다. tsl(=PyG 메시지 패싱) 규약에서 인접행렬 A[i, j]는 j → i 엣지입니다(tsl.ops.connectivity.adj_to_edge_index가 행렬을 전치한 뒤 변환). 반면 이 저장소의 CSV는 a[i, j] > 0을 **i → j (상류 → 하류)**로 씁니다. 원본 prepare_distance_matrix()는 전치하지 않으므로 그대로 쓰면 GNN 메시지가 하류 → 상류로 흐릅니다. 서브클래스에서는 dist.T를 저장합니다.

아래 서브클래스는 원본의 load_data / prepare_* 로직을 그대로 재사용하면서 이 네 가지만 보완합니다.

from tsl.datasets.prototypes import DatetimeDataset
from tsl.ops.similarities import gaussian_kernel


class HydrologyDataset(IJCNNHydrologyDataset, DatetimeDataset):
    """IJCNNHydrologyDataset + (a) 올바른 valid-mask, (b) distance 유사도, (c) DatetimeDataset."""

    similarity_options = {"distance"}

    def __init__(self, adj_matrix_path, discharge_data_path,
                 freq="h", name="Hydrology"):
        self.adj_matrix_path = adj_matrix_path
        self.discharge_data_path = discharge_data_path
        self.freq = freq
        self.missing_values = np.nan

        df, dist, _ = self.load_data()          # 원본 전처리 재사용
        valid_mask = ~df.isna()                 # (a) True = 관측됨
        DatetimeDataset.__init__(self, target=df, mask=valid_mask, freq=freq,   # (c)
                                 similarity_score="distance", name=name)
        # (d) tsl/PyG 규약: A[i, j] 는 "j -> i" 엣지 (adj_to_edge_index 가 전치 후 변환).
        #     CSV 의 a[i, j] 는 "i -> j" (상류 -> 하류) 이므로 전치해서 저장해야
        #     메시지가 상류에서 하류로 흐릅니다. 원본 클래스는 전치하지 않습니다.
        self.dist = dist.T

    def compute_similarity(self, method: str, theta: float = 1.0, **kwargs):
        # (b) MetrLA 방식: 거리행렬에 가우시안 커널 exp(-(d/theta)^2) 을 씌워 유사도로 변환.
        #     MetrLA는 theta = (유한 거리들의 표준편차)를 쓰지만, 이 데이터셋의 거리는 0/1/inf 뿐이라
        #     그 값은 약 0.5 → 엣지 가중치 exp(-4) ≈ 0.02 가 되어 yaml의 threshold=0.1 에 전부 잘려
        #     "엣지가 하나도 없는 그래프"가 됩니다. 그래서 theta=1.0 (가중치 exp(-1) ≈ 0.37) 로 둡니다.
        if method == "distance":
            return gaussian_kernel(self.dist, theta)
        raise NotImplementedError(method)

4. 그래프 연결성: 거리행렬 → edge_index, edge_weight¶

get_connectivity()는 compute_similarity()로 얻은 N x N 유사도 행렬에 threshold(작은 값 제거), include_self(자기 루프), layout(edge_index / dense / sparse) 등을 적용합니다. spin_hydrology.yaml의 dataset.connectivity 블록이 바로 이 인자들입니다.

  • 거리 1.0(연결) → exp(-(1/θ)^2), 거리 inf(비연결) → 0. 즉 인접행렬의 방향(상류→하류)이 그대로 엣지 방향이 됩니다.
  • threshold는 이 가중치에 적용되므로, 커널 폭 θ와 threshold의 조합에 따라 엣지가 전부 사라질 수 있습니다. 항상 엣지 수를 확인하세요.

5. 결측치 마스크: mask vs eval_mask vs training_mask¶

imputation 문제에서는 세 종류의 마스크가 등장합니다.

이름 의미
mask 원본 데이터에서 실제로 관측된 위치 (True = 관측)
eval_mask 평가용으로 일부러 가린 위치. 모델은 학습 시 이 값을 보지 못하고, 테스트 시 이 위치에서 오차를 계산
training_mask mask & ~eval_mask — 모델 입력으로 실제 사용되는 위치

tsl.ops.imputation.add_missing_values()가 eval_mask를 랜덤으로 만들어 데이터셋에 붙입니다(MissingValuesMixin). p_fault(연속 구간 결측 확률, 길이 min_seq~max_seq)와 p_noise(점 결측 확률)는 default.yaml의 p_fault, p_noise에 해당합니다.

6. ImputationDataset: torch 텐서 + 슬라이딩 윈도우¶

여기서부터 pandas → torch로 넘어갑니다. ImputationDataset은

  • target (T, N, C)를 길이 window의 윈도우로 잘라 샘플을 만들고(stride만큼 이동),
  • 각 샘플에 x(입력), y(정답), mask, eval_mask, edge_index, edge_weight, 공변량 u를 담은 Data(PyG Data의 확장)를 돌려줍니다.
  • transform=MaskInput()은 x에서 training_mask == False인 값을 0으로 지웁니다(모델이 정답을 훔쳐보지 못하게).

공변량 u는 시각을 sin/cos로 인코딩한 것(datetime_encoded('day'))입니다. 예제 스크립트는 (T, 2) 전역 공변량을 그대로 넘기지만, 이 tsl 버전의 GRINModel은 노드별 공변량 (T, N, F)만 받습니다(GRINCell이 [x, mask, h, u]를 마지막 축으로 cat). 그래서 여기서는 같은 시각 인코딩을 노드 축으로 브로드캐스트해서 (T, N, 2)로 넘깁니다. tsl은 배열 형상에서 패턴(t n f)을 자동 추론합니다.

8. Imputer + GRINModel 학습¶

tsl.engines.Imputer는 LightningModule입니다. 모델 클래스·옵티마이저·손실·지표를 받아 학습 루프를 처리하며, 특히

  • whiten_prob — 학습 중 관측값을 추가로 무작위로 가려 자기지도(self-supervised) 신호를 만듭니다.
  • scale_target=True — 손실을 스케일된 공간에서 계산.
  • 손실 MaskedMAE — 마스크가 True인 위치만으로 평균 절대 오차를 계산합니다.

모델은 예제 스크립트의 get_model_class()에 있는 것 중 GRIN(그래프 순환 imputation 네트워크)을 사용합니다. filter_model_args_()는 모델 생성자가 받지 않는 키를 kwargs에서 제거해 주는 편의 함수입니다(예제 스크립트와 동일 패턴).

11. Hydra 설정(spin_hydrology.yaml)과 예제 스크립트 연결하기¶

spin_hydrology.yaml은 tsl/examples/imputation/config/default.yaml 위에 덮어쓰는 설정입니다(defaults: [default, _self_]). 그러나 현재 상태로는 실행되지 않습니다:

  1. run_imputation_experiment.py의 get_dataset()은 air*, la, bay 이름만 알고, hydrology는 ValueError를 냅니다.
  2. yaml의 데이터 경로가 Windows 절대경로(E:/...)입니다.

이 노트북에서 만든 HydrologyDataset을 스크립트에 연결하려면 get_dataset()에 아래 분기를 추가하면 됩니다 (cfg.dataset을 통째로 넘기도록 호출부도 한 줄 바꿉니다):

# run_imputation_experiment.py
from hydrology_dataset import HydrologyDataset      # 이 노트북의 서브클래스를 파일로 옮긴 경우

def get_dataset(dataset_cfg, p_fault=0., p_noise=0.):
    name = dataset_cfg.name
    if name == 'hydrology':
        ds = HydrologyDataset(dataset_cfg.adj_matrix_path,
                              dataset_cfg.discharge_data_path)
        return add_missing_values(ds, p_fault=p_fault, p_noise=p_noise,
                                  min_seq=12, max_seq=12 * 4, seed=42)
    ...

# run_imputation() 안에서
dataset = get_dataset(cfg.dataset, p_fault=cfg.get('p_fault'), p_noise=cfg.get('p_noise'))

그리고 yaml을 config 디렉터리에 두고 경로를 덮어써서 실행합니다:

cp spin_hydrology.yaml tsl/examples/imputation/config/
cd tsl/examples/imputation
python run_imputation_experiment.py config=spin_hydrology \
    dataset.adj_matrix_path=$PWD/../../../data/synthetic/adj_matrix.csv \
    dataset.discharge_data_path=$PWD/../../../data/synthetic/merged_discharge_data.csv
